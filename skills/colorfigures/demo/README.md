# Colorfigures demo

Reference figures from April Zhu's skill page, [april-zhu.com/colorfigures](https://april-zhu.com/colorfigures), downloaded on 2026-10-18 and kept unchanged. All of it is April's work.

## Figures

Each one came from the one-line prompt next to it, in a fresh install of the skill, with no code written by hand. They are built single files (the engine is inlined), so they open straight from disk and make no outside requests.

| file | prompt |
|---|---|
| `gumball.html` | a gumball machine where I can put in a coin and turn the crank |
| `kettle.html` | an electric kettle that boils, then clicks itself off when done |
| `recordplayer.html` | a record player: put on a record, drop the needle and it plays |

The editable sources for two more figures (washing machine, vending machine) ship with the skill in `../assets/examples/`.

## Previews

`img/` holds the page's poster (`.webp`, 480x360) and hover clip (`.mp4`) for each figure it shows: the three above plus washer, espresso, vending, toaster, crossing (traffic light), smokealarm, gashapon (capsule toy machine) and musicbox. The last eight are playable in the live demo at [april-zhu.com/colorfigures-demo](https://april-zhu.com/colorfigures-demo).

`preview.jpg` is eight of those posters tiled 4x2 for the repo README.
