# Stand-in fonts

These open-licensed fonts are used only by `matrix.mjs`, to draw a page the
way it lays out on Windows, Linux and Android. They are metric-compatible
stand-ins (same widths and line breaks), not the systems' own fonts.

| Font | Stands in for | Licence | Source |
|---|---|---|---|
| Selawik | Segoe UI (Windows) | SIL Open Font License 1.1 (LICENSE-selawik.txt) | github.com/microsoft/Selawik |
| Arimo | Arial, Helvetica, Liberation Sans | Apache License 2.0 | fonts.google.com/specimen/Arimo |
| Tinos | Times New Roman, Liberation Serif | Apache License 2.0 | fonts.google.com/specimen/Tinos |
| Cousine | Courier New, Liberation Mono | Apache License 2.0 | fonts.google.com/specimen/Cousine |
| Carlito | Calibri | SIL Open Font License 1.1 | fonts.google.com/specimen/Carlito |
| Inconsolata | Consolas (approximate, size-adjusted) | SIL Open Font License 1.1 | fonts.google.com/specimen/Inconsolata |
| DejaVu Sans, DejaVu Sans Mono | Linux defaults, Menlo | Bitstream Vera / DejaVu licence (free) | dejavu-fonts.github.io |
| Ubuntu | Ubuntu's system UI font | Ubuntu Font Licence 1.0 | design.ubuntu.com/font |
| Cantarell | GNOME's system UI font | SIL Open Font License 1.1 | fonts.google.com/specimen/Cantarell |

Files were taken from the Fontsource CDN (Google Fonts builds) and the
Selawik release on GitHub. Segoe UI, SF Pro, Consolas and Roboto themselves
are not included.
