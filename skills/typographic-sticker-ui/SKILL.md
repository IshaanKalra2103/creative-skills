# Typographic Sticker UI

## Core idea

Design the interface as **typography first, UI second**.

The page should feel like an editorial poster, zine, sticker sheet, or experimental digital magazine that happens to be interactive. Text is the main structural element. Images, stickers, icons, badges, widgets, arrows, highlights, and small controls are woven directly into the text rather than being isolated into a grid of conventional cards.

Think:

> **paragraph + collage + interactive UI**

Avoid making every element look like a standard SaaS component.

---

## Visual language

Use a mixture of:

- Oversized typography
- Inline stickers
- Cutout photography
- Hand-drawn icons
- Small illustrations
- Arrows and scribbles
- Highlighted words
- Underlines and circles
- Badges and labels
- Tiny status indicators
- Progress widgets
- Music/player widgets
- Weather widgets
- Calendar snippets
- Pills and toggles
- Small interactive cards
- Unexpected symbols and decorative marks

The composition should feel **assembled**, not templated.

---

## Typography

Be highly experimental with typography.

Do not automatically use one font throughout the page. Explore combinations such as:

- Bold grotesk + handwritten
- Sans-serif + editorial serif
- Condensed display type + monospace
- Huge bold type + tiny utility text
- Italic serif for emphasis
- Handwritten annotations
- Typewriter/mono labels
- Variable font weights
- Mixed case and unusual capitalization

Typography can change scale, weight, style, and even orientation within the same sentence.

### Important

**Do not be afraid to break typographic conventions.**

Experiment with:

- Extremely large words
- One word occupying an entire line
- Words crossing line boundaries
- Slight rotations
- Underlines that extend beyond words
- Text inside sticker shapes
- Text following curves
- Words highlighted with marker-like backgrounds
- Different typefaces for individual phrases
- Small superscript annotations
- Tiny labels attached to larger words

The typography should feel intentional and expressive, not randomly chaotic.

---

## Inline composition

The key design pattern is **inline visual interruption**.

Instead of:

```text
[icon] Build
[icon] Learn
[icon] Explore
```

prefer:

```text
I love [BUILDING sticker] things with
[AI sticker] and making a
[REAL-WORLD IMPACT note].
```

Images can occupy the same visual role as words.

For example:

```text
I'm currently exploring
[small brain sticker] reinforcement learning,
building [laptop sticker] LLM projects,
and looking for [arrow] interesting problems.
```

The reader should experience the page as a continuous visual sentence.

## Stickers and imagery

### Pinterest sourcing

**Use Pinterest as a primary source of visual inspiration and sticker references.**

When the environment allows web/image search:

1. Search Pinterest for sticker and collage references relevant to the subject.
2. Look for visual assets with the right *shape language*, not just literal subject matter.
3. Collect a varied visual vocabulary:
   - Die-cut stickers
   - Hand-drawn doodles
   - Vintage labels
   - Photographic cutouts
   - Scanned illustrations
   - Retro UI graphics
   - Scribbled arrows
   - Badge shapes
   - Cartoon objects
   - Grainy/halftone imagery
4. Use Pinterest references as inspiration for the visual language.
5. Prefer assets that can be legally used or recreated rather than blindly copying a specific artist's work.

Useful Pinterest searches:

The sticker library should feel **curated**, not like a random emoji collection.

## Sticker treatment

Stickers should usually have one or more of:

- White or colored cutout border
- Slight rotation
- Rough edge
- Paper texture
- Shadow
- Tape
- Marker highlight
- Hand-drawn outline
- Halftone texture
- Grain
- Slightly imperfect positioning

Do not make every sticker perfectly aligned.

A little imperfection creates the editorial/collage feeling.

## Interactive widgets

The visual language can contain **real UI controls**, not just decoration.

Small widgets can be embedded directly into the composition:

### Examples

**Progress**

`RL  ███████░░ 72%`

**Music**

`♫  currently playing  ·  ▶`

**Weather**

`☀  18°C  ·  College Park`

**Activity**

`◉  4,398 steps`

**Status**

`●  3 active projects`

**Toggle**

`◉────○`

**Calendar**

`THU → SUN  ·  SF TECH WEEK`

**Action strip**

`💬 Chat   ·   ☕ Coffee   ·   → Collaborate`

These should feel like **small visual objects embedded in the typography**, rather than full dashboard cards.

---

## Layout

Prefer an asymmetric editorial composition.

Avoid:

- Perfect 3-column dashboards
- Repeated equal cards
- Generic hero sections
- Excessive rounded rectangles
- Uniform icon + title + description components
- Everything aligned to the same baseline

Instead use:

- Large areas of negative space
- Uneven text blocks
- Floating stickers
- Overlapping elements
- Different scales
- Occasional rotation
- Strong horizontal rhythm
- Visual pauses
- One or two dominant typographic moments

The page should still be readable.

**Controlled chaos, not actual chaos.**

---

## Color

Use a restrained base with a few expressive accents.

Possible bases:

- Near-black + white
- Warm cream + black
- Soft gray + black

Then introduce 2–4 accent colors such as:

- Acid green
- Electric blue
- Hot pink
- Warm yellow
- Orange
- Lavender

Do not color everything.

Accent colors should create hierarchy.

---

## Interaction philosophy

Interactions should feel like discovering things inside a poster.

Examples:

- Hovering a word reveals a sticker
- Clicking a highlighted phrase expands a mini-widget
- Hovering an image slightly rotates it
- Clicking a badge opens a project
- A music sticker becomes a player
- A weather sticker expands into the forecast
- A progress sticker reveals details
- A handwritten arrow points toward an interactive control

Keep interactions lightweight and delightful.

---

## Motion

Use subtle motion to make the collage feel alive.

Good examples:

- Sticker wobble on hover
- Tiny rotation changes
- Hand-drawn underline animation
- Tape/sticker lift
- Smooth expansion of widgets
- Small floating motion
- Cursor-following decorative elements
- Progress bars animating into place

Avoid excessive animations.

Motion should reinforce the physical/sticker metaphor.

---

## Content density

Prefer **less text with stronger visual treatment**.

Do not fill every empty space.

A good composition might contain only a few sentences, but those sentences should have:

- expressive typography
- embedded imagery
- highlighted phrases
- stickers
- widgets
- visual annotations

Negative space is part of the design.

---

## Design rule of thumb

When deciding between:

> "How would a normal web app display this?"

and

> "How would an experimental magazine/poster display this?"

choose the second.

But preserve usability.

The user should immediately understand:

1. What this page is about
2. What the important content is
3. What is interactive
4. Where they can click
5. What the visual hierarchy is

---

## Quality checklist

Before considering the design finished, check:

- [ ] Typography is the primary visual structure.
- [ ] Text and visual elements are integrated inline.
- [ ] Stickers feel curated and intentional.
- [ ] Pinterest was used for sticker/reference exploration where appropriate.
- [ ] Typography was allowed to vary and experiment.
- [ ] There is enough negative space.
- [ ] The composition is asymmetric but readable.
- [ ] At least some visual objects are genuinely interactive.
- [ ] Widgets feel like part of the collage rather than generic UI cards.
- [ ] Accent colors are used selectively.
- [ ] The page does not look like a conventional SaaS dashboard.
- [ ] The design feels expressive without becoming difficult to use.

## One-sentence design brief

> **Build an experimental editorial interface where a readable paragraph becomes the layout, and typography, Pinterest-inspired stickers, imagery, iconography, and interactive micro-widgets become the punctuation.**
