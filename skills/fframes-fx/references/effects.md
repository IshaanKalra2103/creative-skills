# Effect catalog

44 effects. Generated by `scripts/catalog.py` from the shader headers; do not edit by hand.
Every uniform is listed with its default. `iResolution`, `iTime`, `uSrc` and `uSrcSize` are filled
by fframes / `fx.rs`. Ported from shader-effects-inc/shaders (MIT) unless the `from:` line says otherwise.

## Overlays: composite over SVG with the listed mix-blend-mode

### FilmGrainOverlay · blend `overlay`
`shaders/FilmGrainOverlay.sksl`. FilmGrain for SVG scenes. fframes cannot feed a rendered SVG subtree into a shader, so the grain is drawn as mid-grey noise and composited with mix-blend-mode:overlay (or soft-light). Overlay blending already weights grain away from pure white and black; uBias pushes it further toward the shadows by darkening the noise mean.

uniforms: `uStrength float 0.5`, `uBias float 0.0`, `uAnimated float 1.0`, `uSize float 1.0`

### LightLeakOverlay · blend `screen`
`shaders/LightLeakOverlay.sksl`. LightLeak for SVG scenes: the leak light alone on black, composited with mix-blend-mode:screen over the scene.

uniforms: `uPosition float2 0.95 0.4`, `uSpread float 0.55`, `uIntensity float 0.15`, `uStreaks float 0.6`, `uColorHot color #fff3c4`, `uColorMid color #ff7a2f`, `uColorFringe color #a63d8f`, `uFlicker float 0.35`, `uSpeed float 1`, `uSeed float 0`

note: same light as LightLeak.sksl. Upstream screens in LINEAR light and adds 0.16 x the light (screenGlowComposite); this layer is srgb(1.16 x light), so over black it is exact and over white both give white; mid-tones get more lift than upstream (about +0.1 sRGB on a 50% grey under a 0.2 light) because CSS screen works on sRGB-encoded values. Upstream also raises alpha over transparent areas, which an overlay over an opaque scene does not need.

### Scratches · blend `screen`
`shaders/Scratches.sksl`. fine curved hairline scratches that flicker in place, like worn film stock or a scuffed lens; lay it over any scene with mix-blend-mode:screen (light scratches) or set uColorA dark and use multiply for dark ones.

uniforms: `uColorA color #ffffff`, `uColorB color #000000`, `uScale float 2`, `uThickness float 1`, `uSeed float 0`, `uSpeed float 1`

note: upstream is a generator (colorA streaks on colorB); the defaults are white on black, so the same pixels work as a screen overlay and are shipped as one. The per-cell sin hashes (huge arguments) and the integer bitcast flicker hash become Hoskins float hashes; fwidth() is replaced by its analytic value (scratch layout differs, look and density match). uScale is exponential (exp(scale) cells per height).

### VignetteOverlay · blend `normal`
`shaders/VignetteOverlay.sksl`. Vignette for SVG scenes: a uColor layer whose alpha is the vignette mask, drawn on top with plain source-over (mix-blend-mode:normal, or no blend at all).

uniforms: `uColor color #000000`, `uCenter float2 0.5 0.5`, `uRadius float 0.5`, `uFalloff float 0.5`, `uIntensity float 1`

note: upstream mixes toward uColor in LINEAR light, but SVG compositing mixes sRGB-encoded values. The alpha is corrected so the result matches upstream exactly for a black (or white) uColor on any background: black needs a' = 1 - srgb(1 - a), white a' = srgb(a); other colors interpolate between the two by their luminance (close, not exact). For a pure darkening vignette, mix-blend-mode:multiply with srgb(1 - a) is equivalent.

`shaders/LightLeak.sksl`. warm overexposed film light bleeding in from an anchor point: a soft bloom, two drifting streak bands across the beam and chromatic fringing, slowly breathing. Screened over the image (and raises alpha over transparent areas, like emitted light).

uniforms: `uPosition float2 0.95 0.4`, `uSpread float 0.55`, `uIntensity float 0.15`, `uStreaks float 0.6`, `uColorHot color #fff3c4`, `uColorMid color #ff7a2f`, `uColorFringe color #a63d8f`, `uFlicker float 0.35`, `uSpeed float 1`, `uSeed float 0`

note: exact chain (lightfields.beamLocalFrame, gradientPaints.leakDrift/leakBloom/leakStreaks/ heatDither, lightfields.chromaticHeatTaps, screenGlowComposite). The kit value noise and dither use an integer bitcast hash; here a Hoskins float hash, so the breathing pattern differs per seed but has the same character. uPosition is top-left origin uv. The cover is shot with non-default props (anchor ~(0.7, 0.62) of a square frame, spread ~0.32, over black); with those this port reproduces it (compare/LightLeak_coverprops.png).

### Pixelate

### Sparkle
`shaders/Sparkle.sksl`. twinkling four-ray star glints added as light over the bright parts of an image, tinted by the color beneath.

uniforms: `uSize float 100`, `uIntensity float 10`, `uThreshold float 0.2`, `uRayLength float 5`, `uColorize float 0.45`, `uSpeed float 1`, `uSeed float 0`

## Masks: alpha coverage for wipes and dissolves (drive uProgress 0 to 1)

### IrisWipe
`shaders/IrisWipe.sksl`. a circle grows from uCenter and wipes the layer away inside it (alpha = 1 where the outgoing layer still shows). Animate uProgress 0 -> 1; use as SVG <mask> content.

uniforms: `uProgress float 0.5`, `uCenter float2 0.5 0.5`, `uFeather float 0.1`, `uInvert float 0`

note: exact chain: reveal.radialCornerNormCoord (distance from the centre over the distance to the farthest corner, aspect-corrected) -> revealMask (front remapped by +-feather so 0 and 1 are fully on/off). Output is white, premultiplied, alpha = the reveal factor that upstream multiplies into the child's alpha. uInvert > 0 = upstream invert:true.

### NoiseDissolve
`shaders/NoiseDissolve.sksl`. the classic film dissolve: soft organic blobs eat the layer away as uProgress goes 0 -> 1 (alpha = 1 where the outgoing layer still shows). The pattern never moves.

uniforms: `uProgress float 0.5`, `uScale float 3`, `uSoftness float 0.25`, `uSeed float 0`, `uInvert float 0`

note: exact chain: reveal.fbmCoverageCoord (3-octave MaterialX Perlin fbm, 0.5 + n * 0.9) -> revealMask with feather = softness. The MaterialX lattice hash is an integer Jenkins hash (no bitwise ops in SkSL); here a Hoskins float hash picks the same 8 gradient directions, so the blob layout differs from the cover but size and softness match.

### RadialWipe
`shaders/RadialWipe.sksl`. a clock hand sweeps around uCenter from uStartAngle and wipes the layer away behind it (alpha = 1 where the outgoing layer still shows). Animate uProgress 0 -> 1.

uniforms: `uProgress float 0.5`, `uStartAngle float 0`, `uDirection float 0`, `uCenter float2 0.5 0.5`, `uFeather float 0.1`, `uInvert float 0`

note: exact chain: reveal.angularCoord (UV-delta aspect scaling, as RadialWipe was written; 0 deg = 3 o'clock, clockwise on screen) -> revealMask. uDirection is the compile-time `direction` select as its mode literal: 0 cw (default), 1 ccw, 2 both. The hard edge at the start angle is upstream's too (the coverage wraps 1 -> 0 there). White premultiplied output; uInvert > 0 = upstream invert:true.
